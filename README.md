## 设计原则

**严谨性由数据结构保证，不由提示词祈祷。**

1. **不丢弃，只降级并记账** —— 被淘汰的信息全部留痕。「识别出旧闻/转载」本身是产出，悄悄丢掉等于没做
2. **可信度由规则裁决，模型只做抽取** —— 置信度、阶段、状态全部是确定性规则算出来的，可回归、可审计
3. **过程即产品** —— 主界面展示"怎么得出的"，不是"得出了什么"

## 信源体系

分层轴是**一手性**（这条信息离事件现场有多近），不是发布主体身份——晚点的独家报道比公司的 AI 公关稿更接近一手。

| 类 | 定义 | 核验路径 |
|---|---|---|
| **A** 当事方直述 | 官方公告 / 财报 / 招聘 JD / App 更新日志 | 不需多源交叉，但**阶段要打折**（官方口径≠落地） |
| **B** 原创深度报道 | 有独立采访 / 内部信源 / 调查 | 不强制多源，单源即「深度单源」档 |
| **C** 常规媒体报道 | 基于公开信息的日常报道 | **必须多源交叉** |
| **D** 聚合转载 | 无增量信息的搬运 | 不计独立源，只做归并证据 |
| **E** 观点评论 | 个人判断与分析 | **禁止抽取事实**，只抽判断 |

实测结论与通道决策见 [`docs/信源实测报告.md`](docs/信源实测报告.md)——
原计划 RSSHub 作主通道，实测 5 个路由族里 4 个已失效，
最终 exa 贡献了八成条目。通道权重是跑出来的，不是设计出来的。

## 快速开始

需要 Python 3.11+ 与 Node 18+。完整说明见 [`docs/运行说明.md`](docs/运行说明.md)。

```bash
cp .env.example secrets.env   # 填入自己的 DeepSeek 与 Exa key
source secrets.env
python3 -m pipeline.run --dataset ecommerce   # 跑一轮完整流水线
python3 -m pipeline.export                    # 生成前端 API 快照
cd web && npm install && npm run dev
```

无需任何 key 也能跑的两件事：

```bash
python3 -m pipeline.run --mock --no-exa   # 固定回放替换 LLM，0 次调用跑通全链路
python3 scripts/probe_sources.py          # 复跑信源可采性探测
```
