# 行业与竞对 AI 洞察情报站

面向零售运营 / 商业分析 / 营销场景的公开信息情报系统。持续完成**采集 → 去重 → 核验 → 分类 → 洞察 → 报告**全链路，并沉淀为可复用方案。

观察对象：淘宝天猫 · 抖音电商 · 快手电商 · 小红书电商 + 行业监管
观察领域：商品与零售运营 · 营销与内容生成 · 商家工具与服务 · 数据与商业分析 · 客服与履约

---

## 设计原则

**严谨性由数据结构保证，不由提示词祈祷。**

1. **不丢弃，只降级并记账** —— 被淘汰的信息全部留痕。「识别出旧闻/转载」本身是产出，悄悄丢掉等于没做
2. **可信度由规则裁决，模型只做抽取** —— 置信度、阶段、状态全部是确定性规则算出来的，可回归、可审计
3. **过程即产品** —— 主界面展示"怎么得出的"，不是"得出了什么"

## 信源体系

分层轴是**一手性**（这条信息离事件现场有多近），不是发布主体身份——晚点的独家报道比公司的 AI 公关稿更接近一手。

| 类 | 定义 | 核验路径 |
|---|---|---|
| **A** 当事方直述 | 官方公告 / 财报 / 招聘 JD / App 更新日志 | 不需多源交叉，但**阶段要打折**（官方口径≠落地） |
| **B** 原创深度报道 | 有独立采访 / 内部信源 / 调查 | 不强制多源，单源即「深度单源」档 |
| **C** 常规媒体报道 | 基于公开信息的日常报道 | **必须多源交叉** |
| **D** 聚合转载 | 无增量信息的搬运 | 不计独立源，只做归并证据 |
| **E** 观点评论 | 个人判断与分析 | **禁止抽取事实**，只抽判断 |

27 个候选信源实测结果：**67% 有确定性直采通道**

| 通道 | 数量 |
|---|---|
| 原生 / 直连 RSS | 6 |
| RSSHub | 7 |
| 直抓（SSR） | 5 |
| Exa 间接覆盖 | 9 |

## 快速开始

需要 Python 3.11+。

```bash
cp .env.example secrets.env   # 填入自己的 Exa 与 DeepSeek key
source secrets.env
```

复跑信源可采性探测（无需任何 key）：

```bash
python3 scripts/probe_sources.py
python3 scripts/probe_round2.py
```
